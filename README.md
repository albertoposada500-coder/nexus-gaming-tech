# 🎮 Nexus Gaming Tech

Plataforma de comercio electrónico moderna, interactiva y responsiva, desarrollada para la exhibición, consulta y gestión de un catálogo de productos tecnológicos y hardware gamer.

🔗 **Enlace en producción:** [https://nexus-gaming-tech.vercel.app](https://nexus-gaming-tech.vercel.app)

## 🛠️ Tecnologías utilizadas

- **Frontend:** React.js y JavaScript (ES6+).
- **Estilos:** Tailwind CSS.
- **Despliegue:** Vercel (integración y despliegue continuo mediante CI/CD).

## ⚙️ Instrucciones para ejecutar el proyecto en la computadora local

### 1. Clonar el repositorio

Ejecuta el siguiente comando en la terminal para descargar el proyecto:

```bash
git clone https://github.com/albertoposada500-coder/nexus-gaming-tech.git
```

### 2. Ingresar a la carpeta del proyecto

```bash
cd nexus-gaming-tech
```

### 3. Instalar las dependencias

```bash
npm install
```

### 4. Ejecutar el proyecto

```bash
npm run dev
```

Después de ejecutar el comando, abre en el navegador la dirección local que aparece en la terminal. Si el proyecto utiliza Vite, normalmente será `http://localhost:5173`.
